# svgic

> Интерактивный SVG-клиент для JS/TS/Vue 3/React. Встраивает SVG в DOM, привязывает слои к данным, обрабатывает события, поддерживает попапы, стили и плагины.

## Установка

```bash
npm install @svgic/core
```

## Документация

- Полный API Reference: [docs/api.md](docs/api.md)
- Практические примеры (recipes): [docs/recipes.md](docs/recipes.md)

---

## Ключевые концепции

- **Слои** — `<g id="...">` в SVG-файле. Роль (`interactive` — события и связывание с данными, `data` — слой только на чтение для плагина, либо любая своя строка) задаётся в конфиге, не в SVG. Слои, не перечисленные в конфиге, рисуются как статичный SVG и ядру не видны.
- **Данные** — массив `SvgicItem[]`, привязывается к элементам по совпадению `id`.
- **Инициализация асинхронная** — `await client.ready` перед вызовом `setData()` и API плагинов.
- **Плагины** — расширяют поведение через хуки `onInit`, `onElementClick`, `onElementHover` и т.д.

## Базовый пример (ванильный JS/TS)

```ts
import { Svgic } from '@svgic/core'

const client = new Svgic('#container', {
  src: '/map.svg',
  layers: {
    rooms: { role: 'interactive' },
    // background, labels — не перечислены, рисуются как статичный SVG
  },
  data: [
    { id: 'room-101', title: 'Переговорная' },
    { id: 'room-102', title: 'Опен-спейс' },
  ],
  popup: true,
  style: {
    default: { fill: '#e2e8f0', cursor: 'pointer', transition: 'fill 0.2s' },
    hover:   { fill: '#93c5fd' },
    states:  { busy: { fill: '#fca5a5' }, free: { fill: '#86efac' } },
  },
})

await client.ready

client.on('click', (id, item) => console.log(id, item))
client.setHighlight('busy', ['room-101'])
```

## Vue 3

```vue
<template>
  <SvgicVue src="/map.svg" :data="rooms" :popup="true" @click="onRoomClick" />
</template>

<script setup lang="ts">
import { SvgicVue } from '@svgic/core/vue'
import type { SvgicItem } from '@svgic/core'

const rooms = ref<SvgicItem[]>([{ id: 'room-101', title: 'Переговорная' }])
const onRoomClick = (id: string, item: SvgicItem | null) => console.log(id, item)
</script>
```

## React

```tsx
import { SvgicReact } from '@svgic/core/react'

<SvgicReact
  src="/map.svg"
  data={rooms}
  popup={true}
  onClick={(id, item) => console.log(id, item)}
/>
```

## Публичный API (краткая шпаргалка)

```ts
// Конструктор
new Svgic(selector: string | Element, options: SvgicOptions)

// Ожидание инициализации
await client.ready

// Методы
client.setData(data: SvgicItem[])
await client.setSrc(src: string)          // заменить SVG, подписки on() сохраняются
client.getLayer(id: string)              // разобранный слой, для плагинов
client.on('click' | 'hover' | 'leave', (id, item) => void)
client.setHighlight(state: string, ids: string[])
client.clearHighlight(state?: string)
client.getElement(): SVGSVGElement | null
client.use(plugin: SvgicPlugin)
client.destroy()
```

## Плагины

```ts
import { ZoomPlugin } from '@svgic/core/plugins/zoom'
import { DebugPlugin } from '@svgic/core/plugins/debug'
import { ContentPlugin } from '@svgic/core/plugins/content'

// ZoomPlugin — zoom/pan колесом, перетаскиванием, touch
const zoom = ZoomPlugin({ wheelMode: 'ctrl', focusOnClick: true })
zoom.zoomTo(2)
zoom.focusElement('room-101')
zoom.reset()

// ContentPlugin — текст, картинки и составной контент внутри фигур слоя,
// с позициями из их геометрии. Кандидаты пробуются по порядку, побеждает первый,
// который дал контент И поместился: логотип уступает названию, название — id,
// по мере того как фигуры мельчают.
const content = ContentPlugin({
  sourceLayer: 'rooms',
  content: [
    { type: 'image', href: ({ item }) => item?.logo as string, minHeight: 14 },
    { type: 'text', text: ({ item }) => item?.title as string },
    { type: 'text', text: ({ id }) => id, opacity: 0.5 },
  ],
})

// DebugPlugin — показывает id элементов при наведении (только dev)
const debug = DebugPlugin({ showOn: 'both' })
```

## Хуки плагинов

```ts
interface SvgicPlugin {
  name: string
  onInit?(client): void
  onDestroy?(client): void
  onDataChange?(data, client): void   // на каждый setData() и на инициализации с options.data
  onElementHover?(element, item): void | false   // false отменяет дефолт
  onElementLeave?(element, item): void | false
  onElementClick?(element, item): void | false
}
```

## Типы данных

```ts
interface SvgicItem {
  id: string
  title?: string
  description?: string
  image?: string
  link?: string
  [key: string]: unknown  // кастомные поля
}

interface SvgicOptions {
  src: string                          // URL или SVG-строка
  data?: SvgicItem[]
  layers?: Record<string, { role: 'interactive' | 'data' | string }>
  idAttribute?: string                 // атрибут SVG с id, по умолчанию 'id'
  idMatch?: 'exact' | 'suffix' | ((svgId: string) => string)
  plugins?: SvgicPlugin[]
  popup?: boolean | PopupConfig        // см. docs/api.md
  style?: SvgicStyleConfig             // см. docs/api.md
}
```
